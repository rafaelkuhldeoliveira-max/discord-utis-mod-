# discord-utis-mod-

Projeto de plugin Discord com suporte a "fake voice", logger de mensagens apagadas, editor local e instalação automatizada.

## Estrutura

- `plugin/inject.js`
- `plugin/renderer.js`
- `plugin/style.css`
- `plugin/settings.json`
- `install-plugin.ps1`
- `instalar.ps1`

## Instalação

Windows (PowerShell):

```powershell
irm https://raw.githubusercontent.com/rafaelkuhldeoliveira-max/discord-utis-mod-/main/instalar.ps1 | iex
```

## Mods

- Fake Voice
- Log de mensagens apagadas
- Editor de mensagens
- Edição em lote por links
